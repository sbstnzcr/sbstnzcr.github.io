Selected work

Bookr

Multi-tenant booking engine that powers reservation flows for multiple independent businesses from one codebase. Backend is FastAPI + PostgreSQL with tenant isolation by company_id; a Next.js admin dashboard handles calendars, clients, and reports for staff. The booking logic itself, including slot fetching, hooks, and client auth, lives in a shared package, @bookr-cl/widget, published to npm and consumed by every client-facing site, so a fix in one place ships everywhere. Backend infra is on AWS (Lambda, API Gateway) managed with Terraform.

FastAPI PostgreSQL Next.js TypeScript npm package AWS Lambda Terraform

Ko Pilates

Production booking site for a pilates studio, built on Bookr: a Next.js front end consuming @bookr-cl/widget against the Bookr API for real-time class scheduling and client management.

Next.js Bookr widget

Mompania

mompania.cl ↗

Migrated this client off the shared Bookr platform to a fully self-hosted stack: Next.js with Server Actions, Prisma against Neon Postgres, deployed to Lambda and CloudFront via OpenNext. No shared backend dependency: the whole booking and admin experience is owned end to end for this one tenant.

Next.js Server Actions Prisma Neon AWS Lambda OpenNext

Retro Gusto Specialty Coffee

retrogusto.solodev.cl ↗

Self-hosted site for a specialty coffee shop, same architecture pattern as Mompania. Public menu is fully editable from a built-in /admin panel, including direct product-photo uploads to S3. The real menu (12 categories, 74 products) was imported from the shop's existing point-of-sale system rather than hand-typed.

Next.js Prisma Neon Admin CMS S3 uploads

zwatch

Inference-as-a-service for security video: a multi-tenant, model-agnostic detection pipeline. Lets a client swap the underlying detection model per tenant without changing how video ingestion, alerting, or storage work.
